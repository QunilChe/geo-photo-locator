# 📸 Geo Photo Locator (OSINT AI)

Веб-інструмент для визначення місця на фотографіях за допомогою `geo-sleuth`, локального штучного інтелекту (Ollama) та зворотного пошуку зображень.

## 🚀 Як запустити (One-Click Setup)

1. Встановіть [Python](https://www.python.org/downloads/) (обов'язково додайте його в PATH).
2. Встановіть [Ollama](https://ollama.com/) та завантажте візуальну модель: `ollama pull llava`.
3. Склонуйте цей репозиторій.
4. Просто запустіть файл **`start.bat`** (подвійним кліком).

Скрипт сам створить віртуальне середовище, встановить усі бібліотеки, завантажить необхідні OSINT-скрипти та відкриє веб-інтерфейс.

## ✨ Можливості
- Завантаження фото перетягуванням (Drag & Drop).
- Аналіз EXIF, OCR (розпізнавання тексту) та зворотний пошук (Яндекс/Baidu).
- Локальна ШІ (Ollama) пропонує варіанти локацій на основі підказок та самого фото.
- Збереження GPS-координат прямо в метадані (EXIF) фотографії.
- Система "навчається" на ваших підтвердженнях (база знань).
